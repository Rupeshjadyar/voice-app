Frequently Asked Questions

Is VoicePro Audio Editor 100% free to use?

Yes, VoicePro Audio Editor Studio is completely free. There are no subscriptions, trial limitations, output watermarks, or file size caps.

Are my uploaded audio files stored on a server?

No! All audio decoding, editing, trimming, signal processing, and encoding happens entirely inside your browser memory using the Web Audio API. Your data never leaves your computer or phone.

Which file formats are supported for input and output?

You can import MP3, WAV, AAC, M4A, OGG, WEBM, and FLAC audio. For exporting, you can choose between lossless 16-bit PCM WAV format or high-bitrate MP3 format.

Can I edit audio generated from the Text to Speech tool?

Absolutely! You can generate speech using our AI Voice Generator on the home page, and then bring the audio into this Editor Studio to adjust pitch, speed, EQ, and add sound effects.
